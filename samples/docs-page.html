Install

Install with your package manager, then check the version with acme --version. Press Ctrl + C to stop a running job.

The config file

Settings live in acme.config.json. Values in {curly braces} are replaced at run time, and <angle brackets> mark required fields.

{
  "name": "<project name>",
  "targets": ["web", "worker"],
  "output": "dist/{target}",
  "retries": 3
}

Targets

  • web builds the browser bundle.
  • worker builds the background job runner.
  • all builds both, in parallel when CPU > 2.

Environment values

Use ${NAME} to read an environment variable.
Missing values stop the build with exit code 2.

Note: values are read once, when the job starts. Changes during a run are ignored.

Limits

A project can have up to 20 targets & 5 nested configs. Paths longer than 240 characters fail on Windows.
